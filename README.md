## The tip

> Tip: Your agent doesn't need more context. It needs you to stop pasting the entire repo into every message.

## How it works

`main.ts` (Node, stdlib only) writes the single-line tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validating it is one non-blank line of 1–200 UTF-8 characters.

```sh
node main.ts
```
